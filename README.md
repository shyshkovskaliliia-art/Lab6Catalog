# Лабораторна робота №6 — Каталог книг

Проєкт Expo + React Native + TypeScript з каталогом книг, категоріями, деталями книги, авторизацією Supabase та роллю адміністратора.

## Запуск

1. Встановіть Node.js LTS.
2. Скопіюйте `.env.example` у `.env`.
3. У `.env` вкажіть URL вашого Supabase-проєкту та publishable key.
4. У Supabase відкрийте **SQL Editor** і виконайте `supabase/lab6_setup.sql`.
5. У терміналі виконайте:

   ```bash
   npm install
   npx expo start
   ```

   Для браузера: `npx expo start --web`.

## Ролі

- **Гість**: переглядає каталог, фільтрує книги за категоріями та відкриває деталі.
- **Користувач**: має ті самі можливості та авторизовану сесію.
- **Адміністратор**: може додавати й видаляти книги. Права на запис додатково перевіряються політиками RLS у Supabase.
